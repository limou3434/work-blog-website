2.核心正文

2.1.锚点所在

我们需要一个锚点，作为我们的出发点，我决定选取 懂车帝 这个网站，这个网站对于我们最为主要的内容其实是导航栏，至于内容其实另说。首先导航栏中可以明确分析出车的分类，我们先按照级别、能源、价格、品牌这几个维度来进行分析。

2.2.快速分类

  • 按照级别：新能源、轿车、SUV、MPV、跑车、皮卡、微面、微卡、轻客
  • 按照能源：汽车、柴油、油电混合、新能源、汽油+48V 轻混系统
  • 按照价格：0-10w、10-15w、15-20w、20-25w、25-30w、30-40w、40w 以上
  • 按照产地：德系、日系、美系、国系
  • 按照热牌：奔驰、宝马、大众、奥迪、小米汽车、特斯拉、保时捷、本田、丰田、吉利汽车、坦克、路虎、比亚迪、雷克萨斯、AITO、凯迪拉克、极氪、小鹏汽车、五菱汽车、岚图
车型简单介绍优点缺点
轿车常规三厢 / 两厢家用车，城市通勤主力省油、好开好停、风噪小、舒适度高、保值稳底盘低、烂路容易刮底、后排头部空间一般
SUV运动型多用途车，车身更高更大底盘高通过性好、视野高、装载能力强、坐姿舒服车身重更费油、风噪大、转弯侧倾大、不好停车
MPV多用途商务家用车，主打多人乘坐座位多、后排空间大、座椅舒适、适合全家出行车身太长不好操控、油耗偏高、日常代步笨重
跑车双门运动造型，主打性能颜值加速快、操控好、颜值高、回头率拉满空间极小、底盘极低、实用性差、价格贵
皮卡前座载人、后斗载货两用车型越野强、装载能打、耐用耐造、兼顾家用拉货限行多、市区不方便、车身宽大、油耗高
微面小型面包车，廉价实用价格便宜、空间灵活、能拉人能载货、养护便宜安全配置低、隔音差、舒适性差、行驶质感弱
微卡微型单排 / 双排小货车体型小巧、城乡送货灵活、用车成本低舒适性差、配置简陋、只能短途代步拉货
轻客大型轻型客车，空间超大空间无敌、可改房车 / 客运 / 货运、承载力强体型巨大难停车、油耗高、日常家用不合适
新能源纯电 / 增程 / 插混统称用车电费便宜、静音平顺、智能配置高、不限牌冬天续航缩水、充电依赖桩、保值不如油车
能源类型简单介绍优点缺点
汽油传统燃油车，加 92/95 号汽油加油遍地有、技术成熟、维修便宜、无续航焦虑油耗逐年上涨、怠速噪音大、用车成本逐年高
柴油加柴油，多用于越野 / 皮卡 / 商用车扭矩大、爬坡有劲、比汽油省油、耐用抗造冬天难启动、噪音震动大、市区油品站点少
油电混合油电协作，不用外接充电堵车更省油、平顺安静、不用充电、无续航焦虑不能上绿牌、纯电里程短、价格比同配置油车贵
新能源纯电、增程、插混统称电费极便宜、起步平顺、智能化强、绿牌免购置税高速能耗高、冬季续航打折、电池有衰减顾虑
48V 轻混汽油为主 + 小电机辅助起步更平顺、轻微省油、怠速启停更安静电机功率很小、不能纯电跑、省油效果不明显
价格区间定位介绍优点缺点
0-10 万入门代步级便宜、养护省钱、适合新手买菜代步配置简陋、用料一般、安全和隔音较差
10-15 万家用黄金级配置够用、油耗适中、选择最多、性价比高没有豪华质感、多为普通家用配置
15-20 万进阶家用级空间更大、内饰质感升级、动力更好溢价开始变高、同配置比入门款贵不少
20-25 万中端品质级能买高配合资 / 国产高端新能源、配置拉满落地压力变大、后期保养成本上升
25-30 万豪华入门级豪华品牌入门、用料做工更好、档次感强豪华品牌低配多、性价比偏低
30-40 万正经豪华级品牌力强、动力配置齐全、商务家用都有面养护贵、保险高、维修配件不便宜
40 万以上高端旗舰级顶配用料、旗舰配置、身份档次拉满溢价极高、养车成本高、贬值速度快
产地品牌优点缺点
德系奔驰、宝马、大众、奥迪、保时捷底盘扎实、做工严谨、高速稳、豪华质感强、操控好价格偏高、保养贵、部分车型小毛病偏多、内饰偏老气
日系本田、丰田、雷克萨斯省油耐开、小毛病极少、保值率超高、省心耐用配置偏低、内饰朴素、动力偏肉、设计保守
美系福特、通用（别克 / 雪佛兰 / 凯迪拉克）、特斯拉底盘厚重沉稳、隔音静谧性好、动力储备足、性价比高；美式豪华气场强；特斯拉智能电动、自动驾驶领先、科技感拉满普遍油耗偏高、变速箱顿挫感偶有；部分车型保值率一般、内饰用料偏粗糙；传统美系车小毛病细碎、车机系统本土化适配一般
国系比亚迪、吉利、坦克、小米汽车、AITO、极氪、小鹏、五菱、岚图配置拉满、性价比高、颜值在线、新能源智能领先、功能全部分品牌保值一般、底盘调校功底略弱、高端养护体系不如老牌豪华
