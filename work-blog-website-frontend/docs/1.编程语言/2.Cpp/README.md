# Cpp

本目录是站内体量最大的 C++ 笔记：从 C 与 C++ 的差异、命名空间和缺省参数讲起，拆解类与对象、初始化列表、static、友元和日期类实现，再依次进入动态内存、模板与 STL（string、vector、list、stack 与 queue、deque、set 与 map、无序容器、迭代器）、继承多态与抽象、异常、智能指针、特殊类设计、类型转换与 RTTI、IO 流和线程，最后以搜索二叉树、并查集、图、B 树、Cache 替换算法和正则表达式收尾；组件子目录另有包管理、序列库、压缩库、网络库、测试库、文档库、字符库与日志库的速览，不过空间配置器、B 树、正则表达式等篇目仍是空壳。
