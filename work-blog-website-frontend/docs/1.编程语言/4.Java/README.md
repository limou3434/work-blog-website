# Java

本目录定位是写给有 C/C++ 基础的人看的 Java 快速转型笔记：先导课与基础语法交代语言历史与开发环境，面向对象部分对比面向过程与面向对象，之后依次讲接口、Lambda 与回调，断言、异常与日志，泛型与集合框架，Stream 与文件 IO，多线程与锁，InetAddress 与网络通信，JUnit 单元测试，反射与注解，IDEA 快捷键，以及用 Maven 管理依赖库和用 JNI 调用 C++ 的工程操作；其中反射与依赖库的笔记目前标注为待补充。
