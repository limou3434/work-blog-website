# 开发方向

本目录按“开发什么”划分方向：后端逐篇铺开网络编程、Maven 依赖管理、Spring 与 Spring Boot、JDBC 到 ORM 的存储框架，以及 Sa-Token 鉴权、Elasticsearch 搜索、Sentinel 流控、Nacos 注册、链路追踪、监控和 Dubbo 远程调用；网页开发收拢了 React 与 Vue 从先导到页面组件的教程，外加 TailwindCSS 与 ShadcnUI；桌面开发同时给出 Electron 与 Qt（C++、QML）路线；此外还有移动开发、小程序、浏览器与油猴插件、VuePress 与 WordPress 建站、软件工程与设计模式，以及机器学习入门。各方向成熟度参差，不少篇目仍停留在提纲。
