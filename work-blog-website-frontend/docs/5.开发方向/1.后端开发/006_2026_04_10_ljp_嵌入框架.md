# 嵌入框架

## 1.全面概述

`H2` 是一个开源的轻量级 `Java` 内存数据库，适用于开发、测试和嵌入式使用场景。它具有高性能、易用性和丰富的功能特性，支持内存模式和持久化模式。`jar` 文件大小约为 `2.5 MB`，这个体积是非常小的。

## 2.基本功能

根据 [官方文档](https://www.h2database.com/html/main.html) 可以得知，有三种部署方式：

- `Embedded + disk-based` 嵌入式 + 基于磁盘
- `Embedded + in-memory` 嵌入式 + 基于内存
- `Server + disk-based` 服务器 + 基于磁盘
- `Server + in-memory` 服务器 + 基于内存

但是我一般都是拿来做本地无数据库的数据测试的，在官方网站中写着，想要使用 `H2` 必须引入 `jar` 包（且 `H2` 本身没有任何需要用户配置的依赖项），正常来说我们必须安装一个，但我们可以依赖 `Maven` 来进行快速的安装。

## 3.快速使用

### 3.1.引入依赖

```xml
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <version>1.4.200</version>
    <scope>test</scope>
</dependency>
```
