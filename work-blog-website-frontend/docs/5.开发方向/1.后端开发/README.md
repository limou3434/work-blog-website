# 后端开发

本目录描绘 Java 后端技术栈：网络编程与 Maven 依赖管理打底，Spring 讲它的由来和要解决的问题，Spring Boot 负责快速搭建 Web 服务，存储框架从 JDBC 讲到 ORM；随后按能力横向展开 Sa-Token 的登录与权限校验、Elasticsearch 的全文检索、Sentinel 的流量治理、Nacos 的服务注册与配置、链路追踪与监控、Dubbo 的 RPC 调用，最后用其他框架补充 Python 等杂项；其中链路追踪、监控等篇目目前只有章节框架。
