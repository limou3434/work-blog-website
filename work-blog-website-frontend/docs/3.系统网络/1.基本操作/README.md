# 系统网络

本目录是系统与网络方向的主干，内容大体沿“先会用、再懂原理、最后能部署”推进：操作系统安装与基本指令之后，讲权限、环境变量、文件与磁盘，接着是 vim、gcc/g++、gdb、make、软件包管理与 Git 等日常工具；随后从缓冲区、文件描述符讲到进程、线程、信号、进程通信与守护进程，再进入网络，逐层拆解应用层、传输层、网络层、链路层、物理层，配合套接字编程、序列化、粘包、DNS、URL 请求全过程和网络应用演进史；最后落到远程连接、frp 内网穿透、systemctl、zsh、Nginx、宝塔、Docker、Kubernetes、面板与 ESXi 虚拟主机等部署运维实践，其中物理层、URL 过程等篇目篇幅较短。
