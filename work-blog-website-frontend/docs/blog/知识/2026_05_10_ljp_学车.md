# 汽车品牌知识

## 1.开篇引言

在路上不知道什么车贵重需要小心对待？遇见某些老板的车却不知道其实力究竟如何？自己到底适合那些类型的车？遇见车牌话题不会聊天？泥需要这一篇博客。

## 2.核心正文

### 2.1.锚点所在

我们需要一个锚点，作为我们的出发点，我决定选取 [懂车帝](https://www.dongchedi.com/) 这个网站，这个网站对于我们最为主要的内容其实是导航栏，至于内容其实另说。首先导航栏中可以明确分析出车的分类，我们先按照级别、能源、价格、品牌这几个维度来进行分析。

### 2.2.快速分类

- 按照级别：新能源、轿车、SUV、MPV、跑车、皮卡、微面、微卡、轻客
- 按照能源：汽车、柴油、油电混合、新能源、汽油+48V 轻混系统
- 按照价格：0-10w、10-15w、15-20w、20-25w、25-30w、30-40w、40w 以上
- 按照产地：德系、日系、美系、国系
- 按照热牌：奔驰、宝马、大众、奥迪、小米汽车、特斯拉、保时捷、本田、丰田、吉利汽车、坦克、路虎、比亚迪、雷克萨斯、AITO、凯迪拉克、极氪、小鹏汽车、五菱汽车、岚图

|  车型  |              简单介绍               |                     优点                     |                    缺点                    |
| :----: | :---------------------------------: | :------------------------------------------: | :----------------------------------------: |
|  轿车  | 常规三厢 / 两厢家用车，城市通勤主力 |   省油、好开好停、风噪小、舒适度高、保值稳   |   底盘低、烂路容易刮底、后排头部空间一般   |
|  SUV   |    运动型多用途车，车身更高更大     | 底盘高通过性好、视野高、装载能力强、坐姿舒服 | 车身重更费油、风噪大、转弯侧倾大、不好停车 |
|  MPV   |   多用途商务家用车，主打多人乘坐    |  座位多、后排空间大、座椅舒适、适合全家出行  |  车身太长不好操控、油耗偏高、日常代步笨重  |
|  跑车  |     双门运动造型，主打性能颜值      |      加速快、操控好、颜值高、回头率拉满      |    空间极小、底盘极低、实用性差、价格贵    |
|  皮卡  |     前座载人、后斗载货两用车型      |   越野强、装载能打、耐用耐造、兼顾家用拉货   |    限行多、市区不方便、车身宽大、油耗高    |
|  微面  |        小型面包车，廉价实用         |  价格便宜、空间灵活、能拉人能载货、养护便宜  |  安全配置低、隔音差、舒适性差、行驶质感弱  |
|  微卡  |        微型单排 / 双排小货车        |      体型小巧、城乡送货灵活、用车成本低      |    舒适性差、配置简陋、只能短途代步拉货    |
|  轻客  |       大型轻型客车，空间超大        |  空间无敌、可改房车 / 客运 / 货运、承载力强  |   体型巨大难停车、油耗高、日常家用不合适   |
| 新能源 |       纯电 / 增程 / 插混统称        |  用车电费便宜、静音平顺、智能配置高、不限牌  |   冬天续航缩水、充电依赖桩、保值不如油车   |

| 能源类型 |              简单介绍              |                     优点                     |                    缺点                    |
| :------: | :--------------------------------: | :------------------------------------------: | :----------------------------------------: |
|   汽油   |    传统燃油车，加 92/95 号汽油     |  加油遍地有、技术成熟、维修便宜、无续航焦虑  |  油耗逐年上涨、怠速噪音大、用车成本逐年高  |
|   柴油   | 加柴油，多用于越野 / 皮卡 / 商用车 |    扭矩大、爬坡有劲、比汽油省油、耐用抗造    |   冬天难启动、噪音震动大、市区油品站点少   |
| 油电混合 |       油电协作，不用外接充电       |  堵车更省油、平顺安静、不用充电、无续航焦虑  | 不能上绿牌、纯电里程短、价格比同配置油车贵 |
|  新能源  |        纯电、增程、插混统称        | 电费极便宜、起步平顺、智能化强、绿牌免购置税 |  高速能耗高、冬季续航打折、电池有衰减顾虑  |
| 48V 轻混 |       汽油为主 + 小电机辅助        |     起步更平顺、轻微省油、怠速启停更安静     |  电机功率很小、不能纯电跑、省油效果不明显  |
