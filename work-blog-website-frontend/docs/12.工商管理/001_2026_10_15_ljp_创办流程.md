# 创办流程

给自己定下一个规则，在是事业状态的时候，一切都是利益，一切都是资源，一切都是达文，而非事业状态下，做一个幼稚可爱的人。

## 预先准备

- [x] **确定一个明确的方向，想做成什么事情**：化妆品行业，把工厂做大做强，最终成为品牌公司，实现三个人的财富自由
- [x] **不熟悉的行业不要立刻去做**：目前通过海雅已经熟悉了很多化妆品，并且也对各种平台有一定的认知
- [x] **准备好启动资金或者天使投资**：目前有厂长大人支持，这方面无忧虑
- [x] **不要对外宣张自己正在做什么**：创业道路上最好不要太过招摇，最好只是说自己是打工的，遇人就说行情不好，保护自己，防御恶意，有些人就是杂碎
- [ ] **在进入之前获取所有的人脉资源，并且做思维整理**：正在整理，需要对工厂进行深入了解，待补充...
- [ ] **一定要先做好准备，可以去想要成为某个方向的同类公司里去做刺客偷学，让自己更加熟悉这个行业**：已经在海雅做了一段时间刺客，但是还需要找一份 `ToB` 的运营工作，待补充...
- [ ] **熟悉这个行业并且爱上这个行业，但是有一个很粗暴的方法爱上，那就是获得钱**：考虑通过代运营的陪跑来达成第一桶金的获取，待补充...
- [ ] **知天知地，天文地理，一切可聊**：口才是个问题，这个需要慢慢学习，待补充...
  - [ ] **地域吃食**：国内就按照省份来进行了解，同时可以尝试直接去那个地方旅游，国外就按照国家来进行了解
  - [ ] **烟酒茶礼**：这不得不了解说真的，哪怕有害，一边推荐对茶文化进行深一步了解伤害最小
  - [ ] **时事新闻**：对当前发生的时政新闻进行解读
  - [ ] **行业知识**：自己的主业肯定是需要最了解的，然后其他行业比如汽车行业、相机行业、香水行业、服装行业、奢牌行业等高端行业也必须多少了解一些
  - [ ] **金融股房**：对于股市的走向等也需要了解一下，还有一些房价分布的情况
  - [ ] **装修行业**：这些东西也需要慢慢学习，会影响到工厂装修和家庭装修

## 创业模式

| 创业模式 | 具体内容                                                     | 优势                           | 适用人群                     |
| -------- | ------------------------------------------------------------ | ------------------------------ | ---------------------------- |
| 网络创业 | 在网上开店或在网上加盟                                       | 门槛低成本少风险小方式灵活     | 初涉商海的创业者             |
| 加盟创业 | 加盟创业的方式主要是依靠分享品牌金矿、分享经营诀窍、分享资源支持等，受到众多创业者的青睐。目前连锁加盟分为：直营店铺（总部开店总部管）、特许加盟（你开店，你来管，用总部品牌）、委托加盟（你出钱开店，总部帮你管店） | 利益共享风险共担               | 可满足不同需求的创业者       |
| 团队创业 | 如今，一个由研发、技术、市场融资等各方面组成的具有优势互补的创业团队，是创业成功的法宝，尤其是对高科技的创业公司来说，更是如此 | 资源、能力互补提高创业成功率   | 具有共同兴趣的团队           |
| 内部创业 | 如今，一个由研发、技术、市场融资等各方面组成的具有优势互补的创业团队，是创业成功的法宝，尤其是对高科技的创业公司来说，更是如此 | 无须投资就可获得资源树大好乘凉 | 在企业支持下有创业想法的员工 |
| 兼职创业 | 兼职创业的方式不仅不需要创业者放弃本职工作，而且还能充分利用在工作中积累的商业资源和人脉关系创业，实现“鱼与熊掌得兼”的梦想。但是，一旦我们选择了兼职创业，就表示我们要在主业、副业、工作、家庭等几条战线上同时作战，这对我们的精力、体力、能力、忍耐力都是极大的考验，要量力而行。另外，兼职创业时还要注意不能侵犯受雇公司的权益，以免给自己带来麻烦 | 无须放弃本职工作               | 不愿放弃现有工作又想创业的人 |
| 概念创业 | 凭借自身的创意、点子、想法等创业的方式，我们称之为概念创业。这需要创业者想出的概念必须标新立异，并具有可操作性。只有这样，才能抢先占据市场先机，并有效吸引风险投资商的注意 | 可获得资源、资金、人才等       | 本身没有资源的创业者         |
| 大赛创业 | 大学生创业大赛是一种移植于美国商业计划的竞赛，其宗旨是帮助参赛者展示项目、获得资金、提供平台等。比如，清华大学的王科、邱虹云等人组建的“视美乐”公司，上海交大的罗水权、王虎等人创建的“上海捷鹏”等，都是通过创业大赛获得的发展。对大学生创业者来说，通过这个平台，他们可以熟悉创业程序、储备创业知识、积累创业经验、接触和了解社会等，可谓一举多得 | 为大学生提供创业机会           | 想创业的大学生               |

我自己是试过网络创业、内部创业、兼职创业、大赛创业。

## 合伙规则

- [x] **谨慎和非家人的朋友亲属创业，避免过多的猜疑**：除非这个人非常可信，否则很容易出现猜忌的问题，而家人之前从小是需要引导的，这点我们具备这种条件，同时已经被非家人坑过两次了（长辈早年创业也遇到过同样的问题），目前就只是打算两个人进行创业，加洲叔叔算是一个非常难得可见的优质合作伙伴了
- [ ] **股份划分一定要清楚，尤其是初创团队不要随意变动。实股主出钱，干股主处力。初创伙伴一定要均分，否则就容易出现话语权问题，多的人易过于强势致失误，少的人把自己看成打工的。超过 3 个人最好都是家人，如果有别的合作伙伴后期需要加入，直接以初创团队作为整体合作即可**：这方面已清楚，也被坑过了

## 注册公司

- [x] **提前选好公司地址，如果只是几个相熟的人一起做网络项目，那么租居民楼就可以，不用考虑招聘员工和接待客户的问题；如果是各种工作室，那么创业者也可以租民房，但装修要好一些；如果是贸易类的创业项目，或需要不断招人的项目，则最好选择带有地下停车场的写字楼**：目前已选好写字楼已经租下，因为后续是打算招募员工的，并且也有停车位非常不错
