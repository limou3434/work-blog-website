# 会计学

本章根据 `bilibili` 马勇老师的 [课程](https://www.bilibili.com/video/BV1xm42137D1/?spm_id_from=333.788.videopod.episodes&vd_source=c92c89dbfcf9cc30c48086469621f35b&p=2) 总结而来。

## 1.基础理论

### 1.1.快速定义

按照组织机构的性质，会计可以快速分为：

- 企业会计
- 政府会计

会计是以货币为主要计量单位，采用 **专门的方法和程序**，对企业和行政/事业（政府）单位的经济活动过程及其结果进行准确完整、系统连续的 ==核算== 和 ==监督==（<u>基本职能</u>），以如实反映受托责任履行情况和提供有用经济信息为主要目的的 **经济管理活动**。在基本职能之上还有一些<u>拓展职能</u>，==预测经济前景、参与经济决策、评价经营业绩==。

### 1.2.两个职能

- 会计核算职能（其实也叫反映），是指会计以货币为主要计量单位，对特定主体的经济活动进行确认、计量、记录和报告，核算环节，比如：

  - 确认：是什么？怎么处理？何时处理？（定性） -> 例如，这是原材料增加、银行存款减少，属于采购业务

  - 计量：是多少？（定量） -> 例如，金额十万元

  - 记录：记录信息（登账） -> 例如，写会计分录，登记原材料明细账、银行存款日记账，编制记账凭证

  - 报告：提供会计信息（出表） -> 例如，期末体现在资产负债表存货项目里，提供给信息使用者

- 会计监督职能，审查真实性、合法性、合理性，比如：报销差旅费找会计审核

  - 真实性 -> 票据是不是真的、业务是否真实出差

  - 合法性 -> 发票是否合规，有没有违反制度

  - 合理性 -> 住宿费标准有没有超过公司规定上限，超标不给报销

### 1.3.会计目标

会计目标，向财务报告使用者提供会计信息，信息包含三类：

- 财务状况（资产负债表）
- 经营成果（利润表）
- 现金流量（现金流量表）

会计目标两大内容：

- 反映企业管理层受托责任履行情况
- 帮助财务报告使用者作出经济决策

### 1.4.阅读对象

会计信息使用者包括：投资者、债权人、政府及其有关部门和社会公众等。

- 投资者：关心盈利、分红，判断要不要投资
- 债权人（银行等）：关心偿债能力，能不能收回本金利息
- 政府及其有关部门：税收、监管
- 社会公众：就业、环保等社会责任信息

### 1.5.基本假设

> [!IMPORTANT]
>
> 补充：选定一壶水（会计主体）、顺利烧下去（持续经营）、分段记温度（会计分期）、用温度数值衡量（货币计量）。
>
> - 会计主体类比：选定这一壶水作为观察对象，旁边另一壶水、锅里的汤不算，只盯着这一壶研究什么时候沸腾。对应：只核算特定企业（主体）的经济业务，不混其他主体
> - 持续经营类比：假设这壶加热的水，在烧开前不会中途拿走、壶不会碎、火不会突然断掉，可以一直加热直到沸腾。对应：假定企业不会马上倒闭清算，才能正常计提折旧、摊销
> - 会计分期类比：我们把烧水的全过程，人为切成一段段来看：加热第 一分钟、第二分钟...直到沸腾，分段记录温度变化。对应：把持续经营划分为年度、月度等期间，才有权责发生制，区分本期、下期
> - 货币计量类比：我们统一用温度计的 ℃ 数值来衡量水的冷热（也可以看气泡、听声音，但温度是核心衡量标准）。对应：以货币为主要计量单位，统一衡量企业经营情况

会计基本假设是企业会计做核算职能（确认、计量、记录、报告）的前提，是对会计核算所处时间、空间环境等所作的合理假定，一般假定如下：

- **会计主体（空间范围）**：界定空间范围，会计核算只核算本主体的业务，会计主体 ≠ 法律主体，法律主体一定是会计主体，会计主体不一定是法律主体（我想给谁算个张，就算是个人、城市、全宇宙都可以）
- **持续经营（时间范围）**：假定在可预见的未来，企业正常经营、不会破产清算，折旧、摊销以此为前提
- **会计分期（时间范围）**：把持续经营的活动人为划分为连续、相等的期间（年度（按照公历日历年度 `01.01~12.31` 期间） + 中期（月度、季度、半年度）），因为分期，才有权责发生制、收付实现制，区分本期和下期
- **货币计量（计量尺度）**：以货币作为主要计量单位（不是唯一计量单位），我国记账本位币一般是人民币

> [!IMPORTANT]
>
> 补充：常见会计主体。
>
> - 采购业务，采购方 <-> 销售业务，销售方
> - 投资业务，投资方 <-> 融资业务，融资方
> - 确认一笔负债，应付账款科目 <-> 确认一项资产，应收账款科目
>
> 总公司和分公司的关系上，分公司实际上是没有单独给营业执照的，理解为部门就可以，真正有执照的其实应该叫母公司和子公司。企业集团是会计主体，但不是法律主体。企业集团 = 母公司 + 一堆子公司拼起来的联合体
>
> - 母公司、每一家子公司：各自单独注册，都是独立法人 → 都是法律主体，也都是会计主体
> - “企业集团” 这个整体：没有独立法人资格，不能单独签合同、单独去法院起诉、自己独立担责 → 不是法律主体
> - 但会计上，为了看整个集团整体盈亏，要把母子公司打包在一起编合并报表 → 把集团看作一个会计主体
> - 因此实际上企业集团是个会计概念

> [!IMPORTANT]
>
> 补充：为什么要假设持续经营呢。
>
> 折旧（计提折旧、提折旧）通俗解释。固定资产慢慢变旧、价值一点点减少，会计上分期把这个减少的价值计入成本费用。但这就有个前提了，我们需要持续经营假设，假设企业会一直经营下去，设备、厂房能用很多年，就不用买的时候一次性全部当成费用，而是分摊到使用的每一期。举例子，买一台机器 `10` 万，能用 `10` 年，报废基本不值钱。
>
> - 每年价值损耗 `1` 万
> - 这每年的 `1` 万，就是折旧额
> - 做账把这 `1` 万记进费用，这个动作就叫计提折旧（提折旧）
>
> 但是实际上中国企业的平均寿命是 `6.09` 年左右（计入国企和私企），国企去掉就只有 `2.5~3` 年，因此我们才说这是假设持续经营，否则就无法提折旧。

> [!IMPORTANT]
>
> 补充：权责发生制和收付实现制。
>
> 由于会计分期，才产生了当期/本期与其他期间的差别，从而形成了权责发生制和收付实现制的区别。想象一个公司，一直经营下去。如果我们不切月份、不切年份（没有会计分期），我们只看它从开业到关门的总账。总共收进来多少钱、总共花掉多少钱，最后一算赚多少就完事。根本不用纠结：这笔收入、这笔费用，到底算哪一段时间的。钱什么时候到手，就算什么时候的。钱什么时候付出去，就算什么时候的，就够了。
>
> 但是现在加上会计分期，被我们的需求强行切成一段一段，比如按月份，每个月都要出报表，看这个月赚了多少。麻烦来了：货是这个月卖的，钱下个月才收到那这笔收入，算 “这个月” 还是 “下个月”？于是出现两种判断规则：
>
> - 权责发生制：（企业常用）看事情什么时候发生，这个月把货交付了、交易完成（取得收钱权利）→ 算这个月收入，哪怕钱没到（确认应收账款）
> - 收付实现制：（政府常用）只看钱什么时候到手，下个月钱才打进来 → 算下个月收入

> [!IMPORTANT]
>
> 补充：记账本位币。
>
> 就是企业做账、记账时主要使用的货币，账本上统一用它来计价。
>
> - 我国的会计核算应以人民币为记账本位币
> - 业务收支以外币为主的企业，也可以选择某种外币作为记账本位币，但编制的财务会计报告应当折算为人民币反映
> - 在境外设立的中国企业向国内报送的财务会计报告，应当折算为人民币
