# 常用插件

除了常用插件，这里还会带上 AE 中默认的自带效果一起讲解，先学会操作工具，只有对工具有足够的把握后，才能去复刻别人的风格，最后做出自己的作品。

插件的我会优先讲解，目录层级是 `插件类别 - 插件名称 - 具体效果`，自带的效果通常只是提一嘴。

而分类方法只是按照个人喜好进行分类的，每个人都有自己的喜好，否则 `AE` 官方早就对各种各样的效果进行分类了（而不是全部拉出来变成一个混乱又长的列表）。

值得注意的是，我这里使用的 `AE` 版本是 `AE 2025`，每一个插件的版本号我会在讲解时指明。

#### 3.2.1.构建器物 Sapphire Builder

`Sapphire` 有两种构建器，可以组合所有的单效果，用户也可以选择不使用构建器而直接使用单效果。

`Sapphire` 还提供了一些加载预设的功能（这是一个按钮，不是效果面板里的某个效果），这些效果可以通过构建器加载一个预设效果，也可以通过添加单效果加载一个预设参数，这里对界面稍微翻译一下（一个是构建器内打开的，一个是单效果打开的）。

有些时候针对单效果还会多加一些单独的控件支持。

而且一般我是推荐在选择预设之后，再来微调参数细节的。

##### 3.2.1.1.效果构器 S_Effect

![image-20260923123915534](./assets/image-20260923123915534.png)'

一般都是点击编辑效果，然后这里的界面有点专业，可以研究一下。新版本的 `Sapphire` 还有一个 `Mocha` 功能，以后再来研究这个功能吧，待补充...

![image-20260923130542834](./assets/image-20260923130542834.png)

这里默认有四个节点，其中源头节点、背景节点、遮罩节点是需要在外面选中图层的。这个构建器的操作流程是把效果、蒙板、源头、背景给结点化了。然后点击某个节点就可以在构建器内部进行效果参数调整，保存构建器后就会自动添加对应的效果，新版本的 `Sapphire` 甚至还支持构建器把节点效果中的某一些参数隐藏不暴露出去。因此为什么叫构建器，实际上可以理解为自己使用多种效果给自己定制了一个专属于自己的效果。

而这也是为什么效果构建器中有 `保存预设` 和 `加载预设` 这两个设置，这个功能也支持您把自己设计好的效果做成预设给其他工程进行使用，而且也有一些自带的预设可以使用（这个加载过程比较久，需要等待一段时间）。

![image-20260923131216535](./assets/image-20260923131216535.png)

![image-20260923131449767](./assets/image-20260923131449767.png)

![image-20260923131608524](./assets/image-20260923131608524.png)

这里的遮罩节点默认是纯白色（也就是全部不透明，相当于没有效果），要使用的时候直接连接到效果节点上再拿去链接别的节点就可以达到把效果作为其他效果的遮罩了。不过这里其实我发现我的这个版本的节点编辑器很奇怪（遮罩节点连接了某些效果后，无法继续连接其他效果最后一起作用到结果节点上，再加上缺失很多功能，经常用着用着就奔溃一次...），为了达到最好的效果的话，我进行了插件的升级操作。不过就算是新版本，其实也和之前说的是一样的。

![image-20260923151900431](./assets/image-20260923151900431.png)

这个界面一下就高级了很多，继续我们的学习吧，可以看到这个万花筒的效果下半部分有些透明，这就是渐变作为遮罩带来的效果。

![image-20260923152423941](./assets/image-20260923152423941.png)

和大部分节点编辑器类似，这个构建器也支持节点临时禁用，鼠标右击节点就可以看到了，也支持一键整理节点（虽然沃感觉这个功能没什么太大用处来着...会打扰创作者创作的思路流呢）。

而且这个编辑器内部是支持对特效的动画编辑的，但是沃觉得没太大必要在里面设置，一是对时间轴的把控不方便、二是曲线也比较难调整、三是这些动画本来就是一些效果可以在 `AE` 的时间轴上进行处理有些破坏统一性。但是利用构建起节省参数倒是非常有用的。

##### 3.2.1.2.转场构建 S_Transition

 有些时候素材和素材之间是需要转场的，这样才不会有突兀感（排除一些特殊场景），这个时候就需要使用转场构建器了。给转场前的素材添加 `S_Transition` 后，默认会自带一个画面越来越暗的一个转场场景。

![](./assets/image-20260923155756890.png)

然后会发现这个转场构建器和之前的效果构建器是类似操作的，就是默认的节点有些许不同。

![image-20260923155917855](./assets/image-20260923155917855.png)

这里我随便选择了一个预设效果进行加载，然后打开编辑转场构建器的编辑界面，可以看到这里的节点已经有一些效果在了，也就是刚刚我选的那个效果。这里的节点还是比较好理解的，和之前的效果构建器是差不多使用方法的。

![image-20260923161445975](./assets/image-20260923161445975.png)

不过为什么没有生效呢？主要原因是因为还需要我们自己做一些什么时候发生这个转场，一般需要自己打下关键帧，这样才能出现转场的效果。

![image-20260923161732016](./assets/image-20260923161732016.png)

这里还有个参数比较有意思。

![image-20260923162101097](./assets/image-20260923162101097.png)

如果设置为 `YesL: ignore` 就会直接无视关键帧设置，以整个转场构建器所在的素材的时长来开始生效效果。

#### 3.2.2.发光特效 Sapphire Lighting

- **S_UltraGlow**：超强高级辉光升级版辉光，分层控制 `主要辉光 + 二次余辉`，`RGB` 通道可以单独缩放，做大片柔和电影高光，控制更精细。其中主要辉光是控制具体是哪里发亮，而次要辉光则是控制发亮后是否扩散。而这个效果还附带几个效果 `边缘、大气模拟、高亮` 等效果

  ![image-20260928123320859](./assets/image-20260928123320859.png)

- **S_GlowDarks**：暗部辉光和普通 `Glow` 相反，从暗部区域发光，黑的地方往外发光，适合暗环境的幽冥、黑雾发光特效。值得注意的是，参数是有些类似的

  ![image-20260928124822021](./assets/image-20260928124822021.png)

- **S_GlowEdges**：轮廓边缘辉光只识别物体边缘做发光，内部不发光，适合线框发光、描边光、赛博轮廓光。不过，如果是文字，最好是预合成后再添加，因为文字有边界，需要通过预合成把边界扩大

  ![image-20260928125209390](./assets/image-20260928125209390.png)

- **S_LensFlare**：镜头光晕经典写实镜头光斑，模拟摄像机镜头进光，包含光斑、色散、光斑串，支持多种镜头光学预设，这个效果非常好，有些时候可以达到一些很积极的情绪效果。还有一种使用场景就可以直接当做汽车前照灯使用。它的预设也非常多，某些预设可以用在在天空展示太阳光的视觉效果。而且这个东西的主光源还可以设置遮挡图层，这样某些物体经过主光源后会把主光源暂时遮挡住，很有真实感。如果需要主光源跟踪某个物体，则可以用 `Edit Mocha` 来实现，在 `Mocha` 面板中跟踪好后左上角保存，在勾选选项 `Hotspot Uses Mocha` 也就是 `Mocha` 跟踪，主灯光也可以有闪烁的效果

  ![image-20260928125834389](./assets/image-20260928125834389.png)

- **S_BokehLights**：散景光斑生成大量虚化焦外光斑（`Bokeh`），可以模拟夜景路灯、节日彩灯、虚化光点，支持形状、密度、闪烁动画，老实说我不太爱用这个这个效果，我更加喜欢搜集一些已有的光斑视频直接叠加，这样还更加自然一些，效果也更加多变一些

  ![image-20260928125625024](./assets/image-20260928125625024.png)

- **S_DropShadow**：投影 / 阴影给图层生成柔和投影，可控阴影偏移、模糊、透明度、颜色，比 AE 自带阴影更顺滑、适合文字 / LOGO 合成

- **S_EdgeRays**：边缘射线光只从物体轮廓边缘向外发射放射光束，适合物体描边发光、轮廓神光、科技描边射线

- **S_Flashbulbs**：闪光灯爆闪模拟相机闪光灯瞬间爆亮效果，中心强光 + 扩散光斑，适合镜头闪白、拍照频闪、瞬间闪光

- **S_Glare**：镜头眩光高光区域产生柔和漫反射眩光，模拟镜头进光雾感，柔和漫溢的高光雾，不是硬星芒

- **S_Glint**：星芒闪光点在画面高光点生成锐利的星芒闪光，金属、水珠、灯光上的细碎星光，可控制星芒角度、数量

- **S_GlintRainbow**：彩虹星芒闪光在 S_Glint 基础上增加色散分光，星芒带彩虹色，模拟玻璃、钻石反光的彩色星光

- **S_Glow**：基础辉光蓝宝石最基础的辉光，画面亮部向外柔和发光，支持阈值、发光大小、色彩，基础发光神器

- **S_GlowAura**：光环辉光带有圈层光晕的辉光，像人物周身气场、魔法光环，发光会形成多层环状氛围光

- **S_GlowDist**：扭曲辉光辉光同时附带光学扭曲，发光区域会轻微变形、折射，适合流体、能量、扰动的发光

- **S_GlowNoise**：噪点纹理辉光辉光自带噪波纹理，发光不是平滑的，带颗粒扰动，做火焰、烟雾、粒子质感的光

- **S_GlowOrthicon**：老式摄像管辉光模拟老式正交摄像管的复古辉光，带有复古电视的高光溢出、色偏，复古影视质感

- **S_GlowRainbow**：彩虹色散辉光辉光自带分光色散，发光边缘分离彩虹色，模拟镜头色散、彩色光晕

- **S_GlowRings**：环形辉光生成一圈圈同心环状发光，扩散光圈、冲击波光环、波纹光效

- **S_LensFlareAutoTrack**：自动跟踪镜头光晕在 LensFlare 基础上内置跟踪，可自动跟随画面特征点运动，不用手动 K 帧光斑位置

- **S_Light3D**：3D 空间光源3D 空间里的点光源，支持景深、遮挡，可以在三维空间投射光斑，适合三维合成灯光

- **S_LightLeak**：漏光 / 胶片溢色模拟老胶片暗房漏光，画面边缘粉 / 橙 / 红的柔化色溢，复古胶片感，vlog、怀旧调色常用

- **S_Rays**：体积光束放射状体积光、丁达尔效应，阳光穿过窗户、云层的光束，可控制光束长度、衰减、明暗

- **S_SpotLight**：聚光灯模拟舞台聚光、手电筒锥形光，有光源点、照射范围、羽化边缘、遮挡，可投射蒙版

- **S_Streaks**：拉伸光带高光沿着方向拉成长条光轨，拖尾光、拉丝光，车灯拖影、高速运动光轨

- **S_ZGlow**：Z 通道深度辉光依靠深度 Z 通道做辉光，近处发光强、远处弱，基于空间深度的发光，三维合成景深发光
