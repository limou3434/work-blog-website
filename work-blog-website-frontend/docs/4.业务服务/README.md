# 开发方向

本目录按业务系统拆成存储、缓存、部署、鉴权与智能等服务：存储服务以 MySQL 为主线，从组件部署、数据类型、表约束讲到聚合函数、单表多表查询、内外连接、索引、事务、视图、用户权限，最后落到 C/C++ 连接数据库、连接池原理和实践题，另有内存数据库与索引补充的笔记；缓存服务围绕 Redis，讲基本使用、主从与集群架构、业务接入时机和早期版本源码阅读；部署服务目前只有单机部署，鉴权服务只有空白占位，智能服务则按排查依据、工具厂家、分类和工作流程整理 AI 工具排查清单。
