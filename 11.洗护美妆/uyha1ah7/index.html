1.开品流程

1.1.前期立项

  • 赛道定位：品类（洁面/精华/面霜/面膜等）、目标人群、价格带、卖点、竞品对标
  • 合规预判：先想好功效宣称（美白/祛斑/防晒属于特证，周期很长；保湿、舒缓、修护属于普通化妆品），特证产品周期 6–12 个月甚至更久，普通妆品备案周期一般 1–2 个月，开品节奏差异巨大
  • 预算起订：包材 MOQ、料体 MOQ、打样费、检测费、备案费、设计费全部提前预估

1.2.商标环节

  • 商标检索：优先查第 3 类（化妆品），配套注册 35 类（线上销售、招商）；有出海需求再加对应国家商标
  • 风险排查：近似商标、禁用词、和知名品牌撞名；不要直接用通用词、功效词做商标
  • 提交注册：拿到受理通知书就可以先用 TM 标，R 标要等下证（普遍 6–12 个月），切记商标没查好就做包材、印包装盒，后期商标驳回，全部包材报废

1.3.工厂对接

  • 定产品名称、规格、净含量、香型、肤感、核心原料、宣称文案
  • 工厂出配方框架、INCI 初稿、稳定性方案，同步确认是否有原料资质
  • 输出《产品需求单》：给设计师、包材厂、配方师统一标准

1.4.包材开发

  • 包材选型：瓶/罐/软管/泵头/盖子/内托/彩盒/外箱，挑选材质（PET、亚克力、玻璃、铝箔等）
  • 结构确认：
    • 标准现货包材：周期短、MOQ 低，直接拿图纸
    • 定制开模包材：需要开模具，模具费
  • 包材打样：先白胚样 → 结构样 → 手板样，测试：漏液、适配泵头、和料体相容性（很关键，料体腐蚀包材、变色、析出是高频问题）
  • 包材工艺：丝印、烫金、UV、浮雕、喷镀；不同工艺有起订量、色差、耐摩擦风险
  • 包材封样：确认 OK 之后，封样留存，后续大货对照

1.5.视觉设计

  • 品牌视觉：logo、主视觉、配色、版式
  • 包装设计：瓶身标、彩盒、说明书，强制标注内容（药监局硬性要求，设计稿必须先审合规），产品中文名称、备案人/生产企业名称地址、净含量、全成分表 INCI、保质期/限期使用日期、生产批号、贮存条件、使用方法、警示语等
  • 合规审稿：先自己对照《化妆品标签管理办法》自查，再给工厂/合规顾问复核，定稿后再下印刷，切记，不要到设计稿印完才发现标签缺项，整批彩盒报废

1.6.配方打样

  • 工厂打样：初样 → 调整肤感/香气 → 确认样，双方签样封样
  • 强制检测：
    • 普通品类：微生物、理化、重金属
    • 宣称功效：需要功效评价报告（比如保湿、舒缓）
  • 稳定检测：冷热循环、光照、长期留样，看分层、变色、异味、发霉
  • 防腐检测：防腐效力

1.7.备案证书

  • 准备资料：产品信息、配方、原料安全信息、包材安全评估、检测报告、标签设计稿、生产企业资质
  • 平台填报，上传资料，等待审核；审核通过后，拿到备案号，没有备案号不能上市销售
  • 特化（美白、防晒等）是注册制，不是备案，审批严格很多

1.8.仓库管理

  1. 小试 → 中试（试产）：核对料体、包材匹配、灌装、封口、喷码、包装流水线有没有问题
  2. 封样：料体+包材+成品，三方（品牌、工厂、包材商）留存
  3. 大货排产、生产、质检、入库
  4. 留存生产记录、批次检验报告，以备监管抽查

九、上市后

  • 留样持续观察
  • 宣传文案、详情页合规，不能超范围宣称
  • 每年配合监管抽检

极简时间线（普通化妆品，无定制包材）

商标查询（1–3 天）→ 产品定位（3–7 天）→ 包材选型+设计（7–20 天）→ 配方打样+稳定性（20–40 天）→ 检测+备案（15–40 天）→ 试产+大货（15–30 天） 如果是 定制开模包材，整体再多加 2–4 个月。

给你的学习顺序（贴合你目标）

  1. 先吃透上面这套流程，建立全局时间线，搞懂各个环节谁先谁后、哪些是前置卡点（商标、标签合规）
  2. 再看《化妆品合规与备案实务》，把每个环节的合规细节补上
  3. 再去看包材工艺、印刷、相容性相关内容
  4. 配方不用深挖，学会看懂工厂给你的报告、识别风险即可

如果你想要，我可以给你一份一页版 开品节点表（带每个节点输出物、风险清单），方便你对接工厂和设计师。
